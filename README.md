# DevMarket MVP

React + Vite + React Router software marketplace starter.

Run:
1. npm install
2. copy .env.example to .env.local
3. add Supabase URL/anon key
4. npm run dev

Run `supabase/schema.sql` in Supabase. The source bucket is private. Complete server-only Vercel API routes according to `api/README.md` before production.

This package intentionally does not fake payment success or expose source files.
